# NewsFlow

Frontend da plataforma de newsletters (Vite, React, TypeScript, Tailwind, shadcn/ui).

## Scripts

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — build de produção
- `npm run preview` — pré-visualizar o build
- `npm run test` — testes (Vitest)
- `npm run lint` — ESLint

## Playwright

Testes E2E ficam em `e2e/` (pasta opcional). Com `npx playwright test`, o `webServer` sobe o Vite na porta 8080.
